# Finite-support adequacy certificates

## Purpose and status

Causal4D frequently represents a posterior with a finite rollout bank. A
posterior that is normalized over that bank answers a different question from
whether the bank contains enough of the original support for a registered
physical query.

`FiniteSupportAdequacyCertificateV1` separates those questions. It combines:

- the original prior mass retained by the finite bank;
- retained component likelihoods;
- an upper bound on the likelihood of every omitted component; and
- finite physical bounds on the registered query over omitted support.

The result is analysis and admission infrastructure. It does not alter the
estimator, add a missing component, infer an omitted likelihood from target
outcomes, or establish that a provider supplied a valid physical bound.

## Posterior-mass bound

Let `r` be retained prior mass, let `p_i` be prior weights conditional on the
retained bank, and let `L_i` be component likelihoods on one common arbitrary
scale. If every omitted component has likelihood at most `L_max`, then

```text
Z_retained = r * sum_i p_i L_i
Z_omitted <= (1 - r) * L_max
```

and consequently

```text
P(omitted | evidence)
    <= Z_omitted_upper
       / (Z_retained + Z_omitted_upper).
```

The implementation evaluates this expression in log space. A common additive
shift of all retained log likelihoods and the omitted upper bound changes
neither the result nor the artifact identity. This prevents an arbitrary
likelihood normalization constant from becoming scientific provenance.

The omitted likelihood upper bound must be justified by the provider, an
analytic likelihood ceiling, a source-only envelope, or another preregistered
argument on the same likelihood scale. The certificate never invents it. When
all prior support is retained, the omitted bound is absent and omitted posterior
mass is exactly zero.

## Registered-query mean envelope

For retained-only posterior query mean `mu_R`, omitted posterior mass
`alpha <= alpha_max`, and omitted query value in `[q_min, q_max]`, the complete
posterior mean lies inside the coordinatewise envelope generated by

```text
(1 - alpha) * mu_R + alpha * q_omitted.
```

Because the true omitted mass may be anywhere between zero and `alpha_max`, the
certificate includes `mu_R` itself and reports:

- `full_query_mean_lower`;
- `full_query_mean_upper`; and
- `query_mean_max_abs_shift`.

The bounds apply coordinatewise. They do not assert that all coordinate
endpoints are attained by one common omitted component, and coordinates are not
treated as independent statistical units.

## Example

```python
import numpy as np

from causal4d.support_adequacy import (
    build_finite_support_adequacy_certificate,
    save_finite_support_adequacy_certificate,
)

certificate = build_finite_support_adequacy_certificate(
    support_artifact_id=rollout_bank.artifact_id,
    evidence_id=grouped_evidence.evidence_id,
    query_id=registered_query.query_id,
    support_name="registered intervention and twin bank",
    component_ids=rollout_bank.component_ids,
    query_labels=("late-track-x", "late-track-y", "late-track-z"),
    query_units=("m", "m", "m"),
    retained_prior_mass=0.94,
    retained_prior_weights=conditional_prior_weights,
    retained_log_likelihoods=component_log_likelihoods,
    omitted_log_likelihood_upper_bound=source_frozen_log_likelihood_ceiling,
    retained_query_values=component_query_values,
    omitted_query_lower=np.asarray([-0.25, -0.25, -0.25]),
    omitted_query_upper=np.asarray([0.25, 0.25, 0.25]),
    minimum_retained_prior_mass=0.90,
    maximum_omitted_posterior_mass=0.05,
    fallback_artifact_id=static_physical_fallback.artifact_id,
    metadata={
        "registered_before_target_access": True,
        "omitted_likelihood_bound_source": "source-only envelope v1",
    },
)

if not certificate.admissible:
    use_exact_fallback()

save_finite_support_adequacy_certificate(
    "support-adequacy.npz",
    certificate,
    overwrite=False,
)
```

`retained_prior_weights` are conditional on the retained bank and must sum to
one. `retained_prior_mass` stores the missing normalization relative to the
original support. Supplying posterior weights in place of prior weights would
double count the evidence and is invalid.

## Admission policy

The certificate records two predeclared thresholds:

- minimum retained prior mass; and
- maximum omitted posterior mass upper bound.

It reports deterministic failure reasons and an `admissible` flag. An optional
fallback artifact identity records the intended fallback, but the certificate
does not execute or validate that fallback. Claim-bearing callers should fail
closed and prove exact fallback identity separately.

A high retained prior mass does not by itself imply a low omitted posterior
mass: a small omitted region can dominate after observing evidence if its
likelihood ceiling is much larger than the retained average. Conversely, a
moderate prior truncation can be harmless for a query when omitted likelihood
and query ranges are tightly bounded.

## Strict archive and provenance

The certificate is content addressed and binds:

- support, evidence, and registered-query identities;
- retained component identifiers and conditional prior weights;
- canonical retained log likelihoods and the omitted ceiling;
- prior- and posterior-mass bounds;
- retained query values and omitted physical query limits;
- admission thresholds, decision, failure reasons, and fallback identity; and
- finite immutable metadata.

Archive publication is atomic and non-overwriting on request. Loading uses one
bounded, symlink-safe, non-pickled NPZ snapshot and validates exact members,
dtypes, descriptor fields, all derived quantities, and the content digest.

## Scientific boundary

The certificate says what follows **if** the omitted likelihood and query bounds
are valid. It is not evidence that:

- the original support itself was physically complete;
- the likelihood ceiling covers unmodeled mechanisms;
- the omitted query bounds are correct outside registered conditions;
- the retained posterior is calibrated; or
- frames, nodes, coordinates, particles, or views are independent experimental
  units.

For the frozen 36-execution experiment, introducing a new certificate or bound
after target access would be a method change. Use it only in a separately
versioned future protocol or as non-selective diagnostic reporting already
declared before target access.
